Shapes are sampled onto the existing grid, so the highlight while you drag is the set of cells that will actually change — not the outline you drew. Editing the geometry stops the run and rebuilds the field from the scenario's initial condition: a domain that changes shape mid-flow is a moving-boundary problem this fixed-grid solver does not model.
